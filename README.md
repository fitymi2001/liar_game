# 라이어 게임 v0.1

3~10명이 6자리 방 코드(또는 초대 링크)로 모여 플레이하는 실시간 웹 게임. 로그인 없음.

## 실행

```bash
npm install
npm start          # http://localhost:3000
npm test           # 서버를 시간 배율 0.1로 띄워 여러 클라이언트로 규칙 검증
```

- `PORT` — 포트 (기본 3000)
- `LIAR_TIME_SCALE` — 모든 제한 시간 배율 (테스트용, 예: `0.2`)

## 구성

| 파일 | 역할 |
| --- | --- |
| `server.js` | HTTP + WebSocket 서버. 방·단계·타이머·힌트 권한·투표 집계·점수를 모두 서버에서 결정 |
| `words.js` | 13개 주제 · 248개 제시어와 별칭 (별칭은 라이어 추측 정답으로 인정) |
| `public/index.html` | 클라이언트 (의존성 없는 단일 파일) |
| `test/smoke.js` | 실제 서버 대상 다중 클라이언트 시나리오 테스트 |

## 명세에서 정한 해석

- **제시어 비공개**: 서버가 참가자별로 상태를 따로 만들어 보냅니다. 라이어에게는 결과 단계 전까지 제시어가 전송되지 않습니다.
- **힌트 금칙어 검사는 시민에게만** 적용합니다. 라이어의 힌트를 "제시어 포함"으로 거절하면 그 자체로 제시어가 새어 나가기 때문입니다. 한 글자 별칭(예: 강아지→개)은 오탐을 막기 위해 힌트 검사에서 제외하고 추측 판정에만 씁니다.
- **추측 판정**은 공백·문장부호·대소문자를 무시하고 제시어 또는 별칭과 일치하면 정답입니다.
- **재투표**는 동률 후보만 대상으로 전원이 투표하며, 후보 본인은 다른 후보에게만 투표할 수 있습니다.
- **재접속**: 브라우저 탭마다 참가자 토큰을 sessionStorage에 저장해, 새로고침하거나 연결이 끊겨도 60초 안에 같은 참가자로 복귀합니다. 60초가 지나면 퇴장 처리되고, 그 사람이 참여 중인 라운드가 진행 중이면 라운드를 무효로 하고 점수 없이 대기실로 돌아갑니다.
- **직접 '나가기'** 를 누르면 유예 없이 즉시 퇴장 처리합니다 (진행 중이면 라운드 무효).
- **입장 제한**: 라운드 진행 중(역할 확인~추측)에는 새 참가자를 받지 않고, 대기실과 결과 화면에서만 입장할 수 있습니다. 결과 화면에서 들어온 사람은 다음 라운드부터 참여합니다.
- **라운드 시작 조건**: 3명 이상이며, 연결이 끊긴 참가자가 없어야 합니다.
- 결과 화면에서는 득표 수와 함께 누가 누구에게 투표했는지도 공개합니다.
- 같은 방에서는 제시어를 모두 쓰기 전까지 중복 출제하지 않습니다.

## 로비 (첫 화면)

- 오른쪽에 **지금 열린 방 목록**이 실시간으로 보입니다: 방 이름, 상태(대기 중 / 게임 중 / 가득 참), 방장, 코드, 참가자 수, **참가 · 관전** 버튼.
- 바로 참가할 수 있는 방이 위에 오고, 그다음은 최근에 만든 순서입니다.
- 방을 만들 때 **방 이름**(최대 20자)을 정할 수 있고, 비우면 다른 방과 겹치지 않는 **물고기 이름**이 붙습니다.
- 목록에 뜨므로 코드를 모르는 사람도 들어올 수 있습니다. 내보내기는 방장 메뉴로 합니다.

## 토론 시간 줄이기 / 늘리기

- 토론 중 참가자마다 **줄이기(−) 또는 늘리기(+) 중 하나만, 한 번** 누를 수 있습니다. 누르면 버튼이 사라지고 고른 것만 표시됩니다.
- 한 번에 **토론 시간 ÷ 참가자 수**만큼 바뀝니다 (예: 60초 토론, 5명이면 ±12초).
- **모두 줄이기를 눌러도 최소 10초는 남습니다.** 남은 시간이 10초 이하일 때 줄이기를 누르면 거절되고, 선택권은 그대로 남습니다(늘리기는 가능).
- 누가 무엇을 눌렀는지는 시스템 메시지로 모두에게 보입니다. 관전자는 누를 수 없습니다.

## 최후의 변론 / 찬반 투표

- 투표(재투표 포함)로 최다 득표자가 정해지면 **10초 최후의 변론**을 합니다. 지목된 사람에게는 화면 가운데에 **변론 입력칸**이 나오고(채팅창으로 보내도 됨, 말로 해도 됨), 다른 사람은 그동안 채팅할 수 없습니다. 변론은 화면 가운데 상자에 크게 표시됩니다.
- 이어서 지목된 사람을 뺀 참가자가 **5초 찬반 투표**를 합니다. **찬성이 반대보다 많으면** 지목이 확정되어 기존 규칙대로 진행합니다 (라이어면 제시어 추측, 시민이면 라이어 승리).
- 동수, 반대 우세, 전원 기권이면 **부결**되어 라이어가 승리합니다.
- 모두 투표하면 바로 집계합니다. 결과 화면에 찬반 집계와 각자의 찬반이 공개됩니다.

## 공공장소 모드 (항상 켜짐)

- 역할과 제시어는 마우스를 올리고 있는 동안(휴대폰은 길게 누르는 동안)만 보입니다. 가린 상태에서는 라이어와 시민의 화면이 똑같습니다.
- 열었을 때도 라이어·시민 구분 색(빨강/초록)을 쓰지 않아 멀리서 색으로 알아챌 수 없습니다.

## 점수 규칙

- 기본값: **시민이 이기면 시민 각자 1점, 라이어가 이기면 라이어 3점**. 같은 방에서 누적됩니다.
- 방장이 대기실·결과 화면에서 각각 0~10점으로 바꿀 수 있고, 라운드를 시작할 때의 값이 그 라운드에 적용됩니다.

## 방장 권한

- 참가자 옆 **⋯** 메뉴: **방장 넘기기**, **관전으로 보내기**(대기실·결과 화면에서만), **내보내기**(한 번 더 눌러 확인).
- 관전자는 목록에서 이름을 눌러 내보낼 수 있습니다.
- 진행 중인 라운드의 참가자를 내보내면 나가기와 똑같이 라운드가 무효 처리됩니다.
- 로그인이 없어서 내보낸 사람이 새 닉네임으로 다시 들어오는 것까지 막지는 못합니다.

## 이모지 반응

- 채팅 입력칸과 전송 버튼 사이의 😀 버튼으로 이모지판을 열고 닫습니다. 34가지 이모지(웃음·놀람·의심·화남·억울 등)를 언제든 보낼 수 있고, 관전자도 쓸 수 있습니다.
- 참가자(와 관전자) 옆 🔔 버튼으로 그 사람의 이모지를 **내 화면에서만** 끌 수 있습니다.
- 누르면 화면 아래에서 이름표와 함께 떠오르고, 연타·꾹 누르기로 연사할 수 있습니다. 연타하면 점점 커지고 참가자 목록에 `😂 x12` 같은 배지가 붙으며, 10연타마다 화면 가운데에 크게 터집니다.
- 서버는 한 사람당 순간 20개, 초당 12개까지만 중계합니다 (방 전체가 멈추지 않게).

## 관전자

- 참가자 목록 아래 **관전자 N명** 토글을 눌러야 관전자 이름이 펼쳐집니다.
- 홈 화면의 **관전으로 입장**으로 들어옵니다. 라운드가 진행 중이거나 참가자 10명이 다 찼어도 들어올 수 있습니다 (관전자는 참가자 10명과 별도로 최대 20명).
- 관전자는 라운드에 참여하지 않고(발표 순서·투표 제외) 방장이 될 수 없으며, 점수도 받지 않습니다.
- **제시어와 라이어는 결과 공개 전까지 관전자에게도 보내지 않습니다** (명세의 "제시어는 시민에게만" 조건 유지). 관전자는 주제와 힌트, 투표 진행 상황을 봅니다.
- 관전자는 대기실과 결과 화면에서만 채팅할 수 있습니다. 토론은 참가자끼리만 합니다. 관전자의 메시지에는 '관전' 표시가 붙습니다.
- 대기실·결과 화면에서 **게임에 참가하기 / 관전으로 전환**으로 바꿀 수 있습니다. 방장이 관전으로 바꾸면 남은 참가자 중 가장 먼저 들어온 사람이 방장이 됩니다.
- 관전자의 연결이 끊겨도 라운드에는 영향이 없습니다 (60초 뒤 퇴장 처리만 됨).

이 서버는 WebSocket 연결과 게임 상태·타이머를 **한 프로세스의 메모리**에 들고 있는 구조입니다.
그래서 계속 떠 있는 Node 서버가 필요합니다(Render, Railway, Fly.io 등).
Vercel 서버리스 함수는 WebSocket 연결을 유지하지 못하고 요청마다 인스턴스가 바뀌므로 이 구조 그대로는 동작하지 않습니다.

## v0.1에서 하지 않은 것

- 방·점수는 서버 메모리에만 있어 서버를 재시작하면 사라집니다.
- 방장 강퇴, 토론 조기 종료, 제시어 직접 등록 같은 기능은 없습니다.
